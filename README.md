# BB Malin Iceberg

Общий интерактивный айсберг истории **BOLSHIE BROTHERS MALIN**.

**Сайт:** https://bb-malin-iceberg.bb-malin.workers.dev

Любой посетитель по ссылке может включить режим редактирования, добавлять и изменять события, прикреплять фото, видео и другие файлы. Изменения сохраняются в общей базе и видны всем.

> Доступ открыт: посетители также могут изменять и удалять чужие события и файлы.

## Публикация

Проект собирается командой `npm run build` и разворачивается в Cloudflare командой `npm run deploy:cloudflare`. Перед развёртыванием нужна авторизация Wrangler и база D1, указанная в `wrangler.deploy.jsonc`.
